Политика конфиденциальности Adam

Adam — личное приложение. Его единственный пользователь — владелец приложения.

Какие данные

После согласия владельца на экране Google приложение получает доступ к Gmail (чтение и отправка писем), Google Диску и Google Таблицам аккаунта владельца.

Как используются

Данные используются только для выполнения поручений владельца. Для этого они могут обрабатываться ИИ-моделью Claude (Anthropic), через которую работает помощник. Данные не продаются, не передаются для рекламы и не используются ни для каких других целей.

Хранение

Ключ входа хранится на собственном сервере владельца в закрытом файле. Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Связь

Почта для связи указана на экране согласия Google.

Adam is a personal app used only by its owner. With the owner's consent it accesses the owner's Gmail, Google Drive and Google Sheets solely to carry out the owner's requests; data may be processed by the Claude AI model (Anthropic) for that purpose only, is not sold or used for advertising, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
